## Why

用户希望 seedance-video-agent 直接使用本地 jimeng-web-mcp，替换即梦浏览器操作。Film Studio 已有逐项审批、完整提示词、批准参考集和持久化任务记录，需要保留这些约束。

当前 MCP 的 Seedance 2.0/2.5 仅支持文本和首尾帧，旧 video_mix 不是 Seedance 全能参考；生成/查询返回的主要内容是供人阅读的文本。直接替换会漏传电影参考素材，且无法可靠关联、下载和恢复任务。

## What Changes

- 为 Seedance 2.0/2.5 补齐电影需要的图片全能参考，保持提示词和参考编号顺序，不加入视频/音频参考、视频编辑或超长分镜模式。
- 将真实首帧输入接入生产工具；Film Studio 的连续镜头自动取上一镜当前已选用尾帧。首帧和全能参考是不同模式，设计参考与实际上传输入明确分开，不伪造混用协议。
- 为提交和查询补充稳定的机器可读结果，明确任务身份、状态、媒体类型、结果数量；保留已有工具文本输出和调用方式。
- 依据当前即梦配置核对 Film Studio 的模型和规格映射；未支持的组合在上传/扣费前明确拒绝，不修改项目选择、不降级、不丢弃参考。
- Film Studio 通过一个内部 MCP 适配层提交、查询和下载；不把不受门禁约束的原始生成工具直接交给导演。
- 复用现有 operation 与导入/审核流程。先落提交记录，再发起一次请求；断线恢复只查询原任务，无法确认提交结果时不自动重提。
- sessionid 使用固定的本地私有配置，仅传给 MCP 子进程，不写入项目、提示词、运行 preset 或 Git。
- 图片和视频统一移除浏览器操作与启动依赖；按用户追加要求移除 ChatGPT 生图。更新 Skill、启动配置、恢复文案和测试。

## Impact

- jimeng-web-mcp：视频参考参数、MCP 输出契约、查询结果识别及回归测试。
- seedance-video-agent：受门禁约束的执行工具、MCP 连接与下载、任务状态、配置、执行 Skill 和 UI 文案。
- 不修改 deepseek-harness，不自动迁移或重生成既有电影素材，不绕过登录、平台权限、验证码或审核。
- 实现阶段仅做离线/无扣费检查；付费生成实测需要另行授权。
