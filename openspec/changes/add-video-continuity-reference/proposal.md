# 前镜视频接续参考

## Why
Film Studio 默认用空间走位和提示词表达连续性。用户已明确批准：需要时自动补充参考，同时保留手动切换。现有生产接口仅上传图片，不能使用已选前镜作为视频参考。

## What Changes
- production_submit 增加可选 referenceVideo，含本地路径、审核 SHA256 和预期时长。
- 使用 Seedance 2.5 全能参考生成新片段，保留图片编号；不同于源视频编辑、强制首尾帧或运动预演。
- 提交前核对当前账号规格与输入视频计费配置；不支持则明确拒绝，不降级或重复提交。

## Impact
VideoService、全能参考绑定、生产工具和离线协议测试。无自动付费生成。
